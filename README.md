# MascoSitter

Landing page responsive para presentar la app y sus funciones. El formulario envía los comentarios a `contacto@cear54.com` con la función `mail()` de PHP, usando `no-reply@cear54.com` como remitente.

## Requisitos

- PHP 8.1 o posterior.
- La función `mail()` de PHP habilitada y configurada en el servidor.

## Instalación local con XAMPP

Configura un transporte de correo para PHP en XAMPP. La configuración local de correo es independiente de las credenciales del sitio y no se guarda en este repositorio. Después abre `http://localhost/web_mascositter/`.

El botón de Google Play usa el identificador Android de MascoSitter. App Store se muestra como próximamente y no tiene enlace activo.
